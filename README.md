# Valinabali — галерея турагентства

Адаптивная страница галереи для турагентства: сетка фотографий туров, фильтр по странам и модальное окно заявки. Свёрстана по макету, семантичный HTML и SCSS.

**Демо:** [https://valinabali-omega.vercel.app](https://valinabali-omega.vercel.app)

## Технологии

- HTML5 — семантичная вёрстка, именование по БЭМ
- SCSS — компилируется в `css/style.css`
- SVG-спрайт для иконок
- Без фреймворков и сборщиков — открывается как есть

## Возможности

- Адаптивный лейаут: брейкпоинты для мобильных (≤767px), планшетов (≤1439px) и десктопа
- Адаптивные изображения через `<picture>` + `srcset` с retina-вариантами (2x)
- Сетка галереи с карточками разного размера и подписями к фотографиям
- Фильтр туров по странам, кнопка «Показать ещё»
- Модальное окно с формой заявки на подбор тура: поля с подписями (floating label), состояние ошибки валидации, экран успешной отправки
- Хлебные крошки, бургер-меню для мобильной навигации
- Скрывающиеся заголовки и aria-label для доступности

## Структура проекта

```
├── index.html      # страница галереи
├── css/            # скомпилированные стили
├── scss/           # исходники SCSS
├── fonts/          # шрифты
└── images/         # картинки, SVG-спрайт, retina-варианты
```

## Как запустить

Откройте `index.html` в браузере или поднимите папку любым статическим сервером:

```bash
npx serve .
```
